# Reusable construction patterns

A pattern describes a function, its boundary conditions and the appropriate evidence. Concrete dimensions remain tied to material, print pose and interface.

| Pattern | Function | Essential evidence | Project reference |
| --- | --- | --- | --- |
| Sliding guide with end latch | Separate guidance from retention | Insertion, full travel, release and remaining clearance | OrangePi enclosure, Funnel Guide |
| Crush ribs | Local compliance instead of relying solely on a tight round hole | Exact coupon in the same print pose, assembly and retention force | Sparky, Distributor |
| Printed hand-operated thread | Tool-free adjustment within the available space | Layer direction, thread engagement, access and service load | UniFi mount |
| Split assembly | Accommodate build volume or assembly access | Individual subassembly sequences and the complete closing sequence | CFF12, Bottom Interface |
| Symmetric common part | Reduce variants and spare-part inventory | The same native part in both actual installed poses | Chute guides, Technic plates |
| Laser-cut tab-and-slot joint | Turn flat sheets into a spatial structure | Material thickness and kerf compensation applied exactly once | File-trolley extension |
| Functional labels | Identify parts and controls unambiguously | Legibility on the actual surface and at the print resolution | Sparky, signs |

## From experience to a pattern

A one-off user decision remains a project decision. Rules that repeatedly prove useful receive a shared reference. A demonstrated tool defect is corrected with an appropriate failure case.

[Assembly review](assembly-review.md) and [fits and retention](fits-and-retention.md) provide detailed criteria. Colour roles and edge dimensions belong in profiles.
