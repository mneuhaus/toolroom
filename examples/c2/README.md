# C2 Channel: an assembly manual from CAD

The documented C2 revision contains 45 CAD occurrences, 43 handling units and 20 inventory entries. These counts differ for good reasons: a multipart marker or a complete purchased bearing is not automatically a collection of individually assembled parts.

## Start with assembly order

Eleven native build stages represent subassemblies and their combination. The rotor/gear unit is assembled first, while the six screws underneath remain accessible. Durable stages store final positions; cameras and exploded offsets remain in the illustration recipe.

## One recipe, multiple outputs

The shared recipe produces an eight-page PDF manual and an interactive web edition. The illustrated Brick Manual style highlights newly added printed parts in orange. This colour describes the assembly step and is not a manufacturing requirement.

## Explicitly unresolved items

The manual uses six nominally selected M3×12 rotor screws with engagement checked in CAD. Physical fits and several incompletely specified fastenings remain checks for the first build. The original master assembly is not redesigned from within the manual workflow.

## Transferable rule

CAD part counts, purchased-component counts and assembly inventory are separate layers. A plausible final pose does not replace an accessible screw sequence. An exploded animation illustrates the explanation; it does not automatically establish a verified insertion path.
