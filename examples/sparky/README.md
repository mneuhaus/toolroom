# Sparky: design with protected interfaces

The X/Z unit combines nine printed parts with moving mechanisms and purchased components. Revision R14 translates an instrument design language into actual native geometry: a light structure, graphite moving carriers and orange accents for selected adjustment and clamping functions.

## The essential separation

Three profiles separate visual rules, the specific A1/PLA Matte process and protected interfaces. Small facets, short service IDs and labels are deliberately applied to selected faces. Bearings, wheel stacks, connections and the original X travel retain their function.

The earlier generic templates were adapted: a graphic grid does not move motor holes, typical enclosure walls do not size a loaded carriage, and a deliberately supported print remains a valid option.

## What the example demonstrates

The project documentation connects the nine parts to native checks, preserved interfaces, assembly references and actual slicer files. The R13/R14 comparison uses paired cameras. Images on this website are original artifacts from that comparison.

Physical fit and load testing of the R14 prints were still open in the documented revision. Screen colours are not confirmed filament or RAL matches.

## Transferable rule

A design language describes selection and meaning. For each part, it must be tied to function and manufacturing. A product's character emerges across the whole part family, rather than from a blanket chamfer on every edge.
