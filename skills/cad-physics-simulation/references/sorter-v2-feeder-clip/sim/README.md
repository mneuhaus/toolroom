# Sorter V2 simulation

A physics simulation of the [Sorter V2](https://basically.website/sorter-v2)
LEGO sorting machine: the CAD assembly in MuJoCo, pieces as rigid bodies, the
rotors driven like the real steppers, cameras where the real cameras are, and
a fake control board so the machine's own control software can run against it.

See [AGENTS.md](AGENTS.md) for layout, the asset pipeline, and how the
machine is modelled.
